# DS娘桌宠 · DS Maid Desktop Pet 🐋

一个用 `ds-cutout.png` 做成的**原生 Windows 桌面宠物**：置顶小窗、透明背景、点击穿透，
无论你开哪个网页、哪个应用，它都稳稳地浮在桌面上，轻轻上下浮动。

## ✨ 功能

| 操作 | 效果 |
|---|---|
| **左键拖动** | 移动位置 |
| **单击（左键）** | 随机说一句可爱的话（气泡自动换行、完整显示） |
| **滚轮** | 放大 / 缩小（向前滚放大、向后滚缩小；先点一下桌宠获得焦点） |
| **双击** | 恢复默认大小 |
| **全局按住 F8** | 显示 DeepSeek 余额（任何窗口下都生效，松开隐藏） |
| **右键单击** | 关闭桌宠 |

## 🚀 使用

1. 双击 **`启动桌宠.bat`**（控制台自动隐藏）
2. 桌宠出现在屏幕右下角
3. 开机自启：把 `启动桌宠.bat` 的快捷方式放进 `shell:startup`

依赖：Windows 自带 PowerShell + .NET（无需安装任何东西）；余额查询需要 Node.js（可选）。

## 📁 文件

- `pet.ps1` — 主程序（PowerShell + WinForms 透明窗体，OnPaint 帧绘制、无闪烁）
- `启动桌宠.bat` — 一键启动（纯 ASCII 内容，避免 cmd 编码问题）
- `ds-cutout.png` — 人物抠图（去白底、去文字、无描边）
- `dsh-plugin-source.js` — 同款桌宠的 DSH Web 动态插件源码（参考）

## 🛠 技术要点

- 颜色键控透明（品红）+ 缩放图 alpha 硬边 + 品红吸附 → **无任何描边**
- 浮动动画采用安全帧队列 + OnPaint 直接绘制 → **不闪不崩**
- 全局 F8 热键（RegisterHotKey）→ 余额查询在任意窗口下可用
- 排障：出错自动记录到 `.pet-errors.log`
