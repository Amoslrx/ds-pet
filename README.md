# DS娘桌宠 · DS Maid Desktop Pet 🐋

一个用 `ds-cutout.png` 做成的**原生 Windows 桌面宠物**：置顶小窗、点击穿透透明背景，
无论你开哪个网页、哪个应用，它都稳稳地浮在桌面上。

## ✨ 功能

| 操作 | 效果 |
|---|---|
| **左键拖动** | 移动位置 |
| **右键拖动** | 旋转（绕脚底中心转圈圈） |
| **滚轮** | 放大 / 缩小（0.35× ~ 3×） |
| **单击（左键，不拖动）** | 随机说一句可爱的话（气泡跟随头部，文字始终正立） |
| **双击** | 恢复初始大小和角度 |
| **按住 F8**（先点击桌宠获得焦点） | 显示 DeepSeek 余额（读取 `~/.dsh/.credentials.yaml` 的 `DEEPSEEK_API_KEY`） |
| **右下角「-」** | 最小化桌宠（只剩 + 和 -） |
| **最小化时「+」** | 恢复显示 |
| **最小化时「-」** | 退出桌宠 |

## 🚀 使用

1. 双击 **`启动桌宠.bat`**（或在终端执行 `powershell -File pet.ps1`）
2. 桌宠出现在屏幕右下角
3. 想让它在开机时自启：把 `启动桌宠.bat` 的快捷方式放进 `shell:startup`

依赖：Windows 自带 PowerShell + .NET（无需安装任何东西）；余额查询需要 Node.js（可选）。

## 📁 文件

- `pet.ps1` — 主程序（PowerShell + WinForms 透明置顶窗体）
- `启动桌宠.bat` — 一键启动
- `ds-cutout.png` — 人物抠图（去白底、去文字、无白边）
- `dsh-plugin-source.js` — 同款桌宠的 DSH Web 动态插件源码（Host + Client），供参考
